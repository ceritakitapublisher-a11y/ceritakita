DomaiNesia & cPanel Deployment Kit

Gunakan kode MySQL dan PHP di bawah ini untuk membuat website dinamis Anda berjalan di hosting DomaiNesia.

Langkah 1: Skema Database (MySQL)

Gunakan tab phpMyAdmin di cPanel DomaiNesia Anda untuk mengeksekusi script SQL ini.

CREATE DATABASE IF NOT EXISTS ceritakita_db;
USE ceritakita_db;

CREATE TABLE IF NOT EXISTS naskah (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nama_penulis VARCHAR(100) NOT NULL,
    email_penulis VARCHAR(100) NOT NULL,
    telp_penulis VARCHAR(20) NOT NULL,
    genre_buku VARCHAR(50) NOT NULL,
    judul_naskah VARCHAR(150) NOT NULL,
    sinopsis TEXT NOT NULL,
    tanggal_kirim TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    status_proses VARCHAR(20) DEFAULT 'Direview'
);

Langkah 2: Koneksi Database (`config.php`)

Buat file `config.php` melalui File Manager cPanel DomaiNesia Anda di folder `public_html`.

<?php
define('DB_SERVER', 'localhost');
define('DB_USERNAME', 'namauser_db'); // Sesuaikan dengan user cPanel Anda
define('DB_PASSWORD', 'password_anda'); // Sandi database
define('DB_NAME', 'namauser_ceritakita_db');

$conn = mysqli_connect(DB_SERVER, DB_USERNAME, DB_PASSWORD, DB_NAME);

if($conn === false){
    die("Koneksi gagal: " . mysqli_connect_error());
}
